# Hello, Type Editor!

A Markdown editor that renders as you type. Leave a line and its syntax becomes
formatted text; put the caret back and the source returns. Formulas, tables,
footnotes and raw HTML all render in place, and the document exports to PNG or
Word when you are done.

| Key | What it does |
| --- | --- |
| Ctrl+N / Ctrl+O | New / Open |
| Ctrl+S | Save |
| Ctrl+Shift+A | Auto-save interval |
| Ctrl+F | Find and replace |
| Ctrl+/ | Source mode |
| Ctrl+E | Inline code |
| Ctrl+Shift+K | Code block |
| Ctrl+, | Settings |

The **Outline** button lists every heading. **Focus** and **typewriter** modes
live under View. Themes, fonts, text width and the interface language are all in
Settings — and this page is always there under **Home**.

> Start typing to replace this page, or press Ctrl+N for an empty document.
